    🚀 Guide : Vibe Coder avec une IA (Vibe) pour BTS SIO

    Public cible : Étudiants de 2e année BTS SIO (développement PHP/Symfony sous Ubuntu 26.04 + PHPStorm)
    Objectif : Apprendre à utiliser une IA (comme Vibe) pour coder plus efficacement, comprendre des concepts, et résoudre des problèmes, tout en restant autonome et critique.

    📌 Sommaire

    1. Pourquoi utiliser une IA pour coder ?
    2. Les bases du "Vibe Coding"
    3. Utiliser Vibe en CLI (Terminal Ubuntu)
    4. Utiliser Vibe dans PHPStorm
    5. Cas pratiques avec PHP/Symfony
    6. Bonnes pratiques et pièges à éviter
    7. Exercices pour s’entraîner
    8. Ressources utiles

    1. 🤖 Pourquoi utiliser une IA pour coder ?

    ✅ Avantages

    • Gain de temps : Génération rapide de code boilerplate (ex: entités Symfony, requêtes SQL).
    • Compréhension : Explications simplifiées de concepts complexes (POO, design patterns, etc.).
    • Débogage : Aide à identifier et corriger des erreurs.
    • Apprentissage : Accès à des exemples concrets et des bonnes pratiques.
    • Veille technologique : Découverte de nouvelles bibliothèques ou méthodes.

    ⚠️ Limites à connaître

    • L’IA ne remplace pas la réflexion : Elle propose des solutions, mais c’est à vous de les comprendre, tester et adapter.
    • Erreurs possibles : Une IA peut générer du code incorrect ou non optimisé. Toujours vérifier !
    • Confidentialité : Ne partagez jamais de code propriétaire ou sensible.
    • Dépendance : Utilisez l’IA comme un outils d’aide, pas comme une béquille.

    💡 Analogie :
    Une IA, c’est comme un collègue expérimenté qui vous donne des conseils, mais qui ne fera pas le travail à votre place.

    2. 🎯 Les bases du "Vibe Coding"

    Qu’est-ce que le "Vibe Coding" ?

    C’est une méthode de collaboration homme-IA pour :

    1. Générer du code ou des idées.
    2. Comprendre des concepts.
    3. Itérer ensemble pour améliorer une solution.

    Comment bien formuler ses demandes ?

    ❌ Mauvaise demande ✅ Bonne demande
    "Aide-moi avec Symfony." "Donne-moi un exemple de Controller Symfony pour afficher une liste d’articles depuis une base de données MySQL."
    "Mon code ne marche pas." "J’ai cette erreur en PHP : Call to undefined method App\Entity\User::getFullName(). Voici mon code : [insérer extrait]."
    "Explique-moi la POO." "Explique-moi l’héritage en PHP avec un exemple concret (ex: une classe Vehicule et une classe Voiture qui hérite de Vehicule)."

    Exemple de workflow

    1. Décris ton objectif : "Je veux créer une API REST avec Symfony pour gérer des utilisateurs."
    2. Demande un exemple : "Peux-tu me donner un exemple de UserController avec les méthodes CRUD ?"
    3. Itère : "Maintenant, comment ajouter une validation des données avec des annotations ?"
    4. Teste et corrige : Exécute le code, repère les erreurs, et demande des explications si besoin.

    3. 🖥️ Utiliser Vibe en CLI (Terminal Ubuntu)

    Prérequis

    • Un terminal Ubuntu 26.04.
    • Vibe CLI installé (à demander à votre professeur pour l’installation).

    Commandes de base

    Commande Description
    vibe Lance Vibe en mode interactif (comme un chat).
    vibe "[ta question]" Pose une question directement en ligne de commande.
    vibe --code "[description]" Génère du code (ex: vibe --code "Crée un UserController Symfony avec CRUD").
    vibe --explain "[concept]" Demande une explication (ex: vibe --explain "les interfaces en PHP").

    Exemples concrets

    🔹 Générer un fichier PHP

    vibe --code "Crée un fichier PHP classe User avec des propriétés (id, name, email) et des getters/setters."

    → Vibe générera un fichier comme ceci :

    <?php

class User
{
    private int $id;
    private string $name;
    private string $email;

    // Getters et Setters
    public function getId(): int { return $this->id; }
    public function setId(int $id): void { $this->id = $id; }

    public function getName(): string { return $this->name; }
    public function setName(string $name): void { $this->name = $name; }

    public function getEmail(): string { return $this->email; }
    public function setEmail(string $email): void { $this->email = $email; }
}

    🔹 Expliquer un concept

    vibe --explain "À quoi sert le mot-clé 'static' en PHP ?"

    → Réponse :

    En PHP, static permet de définir des propriétés ou méthodes partagées par toutes les instances d'une classe (sans avoir besoin de créer un objet). Exemple :

    class Counter {
    public static int $count = 0;
    public static function increment() { self::$count++; }
}
Counter::increment(); // Appel sans instanciation

    🔹 Déboguer du code

    vibe "J’ai cette erreur : 'SQLSTATE[42S22]: Column not found: 1054 Unknown column 'user_id' in 'where clause''. Voici ma requête : SELECT * FROM users WHERE user_id = 1;"

    → Réponse :

    L’erreur indique que la colonne user_id n’existe pas dans la table users. Vérifie :

    1. Le nom exact de la colonne (ex: id au lieu de user_id).
    2. Que la table users contient bien cette colonne (fais un DESCRIBE users; en SQL).

    4. 🛠️ Utiliser Vibe dans PHPStorm

    Prérequis

    • PHPStorm installé (version récente).
    • Plugin JetBrains IA assistant installé (à demander à votre professeur).

    Comment l’activer ?

    1. Ouvrir PHPStorm.
    2. Aller dans Settings > Plugins et activer le plugin JetBrains IA assistant (ou l’installer via le marketplace).
    3. Redémarrer PHPStorm.

    Fonctionnalités clés

    Fonctionnalité Comment faire Exemple
    Chat avec Vibe Ouvrir la fenêtre JetBrains IA assistant "Explique-moi comment fonctionne le routage dans Symfony."
    Générer du code Sélectionner du code ou un commentaire, puis clic droit > IA Actions > Generate Code. Sélectionner // TODO: Créer une méthode pour valider un email → Vibe propose une implémentation.
    Complétion intelligente En cours d’écriture, appuyer sur Tab pour accepter une suggestion de Vibe. Taper public function get → Vibe suggère getName(), getEmail(), etc.
    Explication de code Sélectionner un bloc de code, puis clic droit > IA Actions > Explain code. Sélectionner une classe Symfony → Vibe explique son rôle.
    Correction de code Sélectionner du code avec une erreur, puis clic droit > IA Actions > Find problems. Sélectionner une boucle foreach mal écrite → Vibe propose une correction.

    Exemple : Générer un Controller Symfony

    1. Dans PHPStorm, créer un nouveau fichier UserController.php dans src/Controller/.
    2. Écrire un commentaire : 
       <?php
 // TODO: Créer un UserController avec une méthode pour lister les utilisateurs (GET /users)
    3. Sélectionner le commentaire, puis clic droit > Vibe > Generate Code.
    4. Vibe générera : 
       <?php
 namespace App\Controller;

 use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
 use Symfony\Component\HttpFoundation\Response;
 use Symfony\Component\Routing\Annotation\Route;

 class UserController extends AbstractController
 {
     #[Route('/users', name: 'app_users', methods: ['GET'])]
     public function listUsers(): Response
     {
         // Exemple : Récupérer les utilisateurs depuis une entité User
         $users = $this->getDoctrine()->getRepository(User::class)->findAll();

         return $this->render('user/list.html.twig', [
             'users' => $users,
         ]);
     }
 }

    Exemple : Expliquer une méthode Symfony

    1. Sélectionner la méthode listUsers() ci-dessus.
    2. Clic droit > Vibe > Explain.
    3. Vibe répondra :

      Cette méthode listUsers() est une action de controller Symfony :

      • #[Route] : Définit la route /users accessible via une requête GET.
      • getDoctrine() : Accède à l’EntityManager pour interagir avec la base de données.
      • findAll() : Récupère tous les utilisateurs de l’entité User.
      • render() : Affiche le template Twig user/list.html.twig en passant la variable users.

    5. 💻 Cas pratiques avec PHP/Symfony

    Cas 1 : Créer une entité Symfony avec Doctrine

    Demande à Vibe :

    "Crée une entité Symfony Product avec les propriétés suivantes :

    • id (int, clé primaire)
    • name (string, 255 caractères)
    • price (float)
    • createdAt (datetime)
      Inclus les annotations Doctrine et les getters/setters."

    Réponse attendue :

    <?php

namespace App\Entity;

use Doctrine\ORM\Mapping as ORM;

#[ORM\Entity]
#[ORM\Table(name: 'products')]
class Product
{
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column(type: 'integer')]
    private int $id;

    #[ORM\Column(type: 'string', length: 255)]
    private string $name;

    #[ORM\Column(type: 'float')]
    private float $price;

    #[ORM\Column(type: 'datetime')]
    private \DateTimeInterface $createdAt;

    // Getters et Setters
    public function getId(): int { return $this->id; }

    public function getName(): string { return $this->name; }
    public function setName(string $name): void { $this->name = $name; }

    public function getPrice(): float { return $this->price; }
    public function setPrice(float $price): void { $this->price = $price; }

    public function getCreatedAt(): \DateTimeInterface { return $this->createdAt; }
    public function setCreatedAt(\DateTimeInterface $createdAt): void { $this->createdAt = $createdAt; }
}

    Prochaine étape :

    • Demander à Vibe : "Comment générer les migrations pour cette entité ?"
    • Ou : "Comment créer un repository personnalisé pour cette entité ?"

    Cas 2 : Écrire une requête DQL (Doctrine Query Language)

    Demande à Vibe :

    "J’ai une entité Product et une entité Category (relation ManyToOne). Écris une requête DQL pour récupérer tous les produits de la catégorie 'Électronique' triés par prix décroissant."

    Réponse attendue :

    // Dans un Repository ou un Controller
$query = $entityManager->createQuery(
    'SELECT p FROM App\Entity\Product p 
     JOIN p.category c 
     WHERE c.name = :categoryName 
     ORDER BY p.price DESC'
);
$query->setParameter('categoryName', 'Électronique');
$products = $query->getResult();

    Explication supplémentaire :

    • JOIN p.category c : Jointure avec l’entité Category (supposée liée à Product via une propriété category).
    • :categoryName : Paramètre sécurisé pour éviter les injections SQL.

    Cas 3 : Corriger une erreur Symfony

    Erreur :

    "J’ai cette erreur : The attribute #Routein methodApp\Controller\ProductController::show was never imported."

    Demande à Vibe :

    "Comment corriger cette erreur dans mon controller Symfony ?"

    Réponse attendue :

    Il manque l’import de l'attribut Route. Ajoute cette ligne en haut de ton fichier :

    use Symfony\Component\Routing\Attribute\Route;

    Cas 4 : Comprendre la POO en PHP

    Demande à Vibe :

    "Explique-moi la différence entre une classe abstraite et une interface en PHP, avec des exemples concrets."

    Réponse attendue :

    Classe Abstraite Interface
    Peut contenir des méthodes avec implémentation. Ne contient que des méthodes abstraites (sans corps).
    Peut avoir des propriétés. Ne peut pas avoir de propriétés (sauf constantes).
    Une classe peut hérité d’une seule classe abstraite. Une classe peut implémenter plusieurs interfaces.
    Exemple : Exemple :

    Classe Abstraite :

    abstract class Animal {
    protected string $name;

    public function __construct(string $name) {
        $this->name = $name;
    }

    abstract public function makeSound(): string;

    public function getName(): string {
        return $this->name;
    }
}

class Dog extends Animal {
    public function makeSound(): string {
        return "Woof!";
    }
}

    Interface :

    interface Loggable {
    public function log(string $message): void;
}

class FileLogger implements Loggable {
    public function log(string $message): void {
        file_put_contents('log.txt', $message, FILE_APPEND);
    }
}

    6. 🎓 Bonnes pratiques et pièges à éviter

    ✅ À faire

    1. Soyez précis : Plus votre demande est détaillée, meilleure sera la réponse.
    2. ❌ "Aide-moi avec Symfony."
    3. ✅ "Donne-moi un exemple de FormType Symfony pour un formulaire de création d’utilisateur avec validation."
    4. Itérez : Ne vous contentez pas de la première réponse. Demandez des améliorations ou des explications supplémentaires.
    5. Testez toujours le code : Une IA peut faire des erreurs. Exécutez le code dans PHPStorm ou en CLI pour vérifier.
    6. Comprenez avant de copier : Ne copiez pas bêtement le code généré. Lisez-le, modifiez-le, et assurez-vous de le comprendre.
    7. Utilisez des commentaires : Dans PHPStorm, commentez votre code avant de demander à Vibe de le compléter. 
       // TODO: Créer une méthode pour calculer le prix TTC d'un produit
    8. Documentez-vous : Utilisez les réponses de Vibe comme point de départ, puis consultez la documentation officielle de Symfony ou PHP.

    ❌ À éviter

    1. Demander des solutions clés en main : L’objectif est d’apprendre, pas de copier-coller sans réfléchir.
    2. Partager du code sensible : Ne partagez jamais de mots de passe, clés API, ou code propriétaire.
    3. Ignorer les erreurs : Si Vibe génère du code qui ne fonctionne pas, ne l’ignorez pas : demandez des explications.
    4. Dépendre uniquement de l’IA : Utilisez Vibe comme un outil, pas comme une solution unique.

    7. 📝 Exercices pour s’entraîner

    Exercice 1 : Générer une entité Symfony

    Consigne :
    Utilisez Vibe (en CLI ou dans PHPStorm) pour générer une entité Symfony Order avec les propriétés suivantes :

    • id (int, clé primaire)
    • orderDate (datetime)
    • totalAmount (float)
    • status (string, valeurs possibles : 'pending', 'shipped', 'delivered')
    • Une relation OneToMany avec l’entité Product (un panier peut contenir plusieurs produits).

    Étapes :

    1. Demandez à Vibe de générer l’entité.
    2. Vérifiez que les annotations Doctrine sont correctes.
    3. Générez les migrations avec php bin/console make:migration.
    4. Appliquez les migrations avec php bin/console doctrine:migrations:migrate.

    Exercice 2 : Créer un Controller Symfony

    Consigne :
    Créez un OrderController avec les méthodes suivantes :

    • list() : Affiche la liste de toutes les commandes (route : /orders).
    • show(int $id) : Affiche les détails d’une commande (route : /orders/{id}).

    Étapes :

    1. Utilisez Vibe pour générer le controller.
    2. Injectez le OrderRepository pour récupérer les données.
    3. Utilisez Twig pour afficher les résultats dans des templates.

    Exercice 3 : Déboguer du code PHP

    Consigne :
    Le code suivant génère une erreur. Utilisez Vibe pour la corriger et expliquer pourquoi elle se produit.

    class User
{
    private $name;

    public function __construct($name) {
        $this->name = $name;
    }

    public function getName() {
        return $this->name;
    }
}

$user = new User("Alice");
echo $user->name; // Erreur ici

    Questions :

    1. Quelle est l’erreur ?
    2. Comment la corriger ?
    3. Pourquoi cette erreur se produit-elle ?

    Exercice 4 : Comprendre les Services Symfony

    Consigne :

    1. Demandez à Vibe : "Explique-moi ce qu’est un service dans Symfony et comment en créer un."
    2. Créez un service Logger qui :
    3. A une méthode log(string $message) qui écrit le message dans un fichier var/log/app.log.
    4. Est injectable dans un controller.
    5. Utilisez ce service dans un controller pour logger un message.

    Exercice 5 : Requêtes SQL avec Doctrine

    Consigne :
    Vous avez une base de données avec les tables suivantes :

    • users (id, name, email)
    • orders (id, user_id, total, date)

    Écrivez une requête DQL pour :

    1. Récupérer tous les utilisateurs qui ont passé une commande de plus de 100€.
    2. Récupérer le total des commandes par utilisateur, trié par total décroissant.

    Astuce : Utilisez Vibe pour vous aider à écrire les requêtes.
