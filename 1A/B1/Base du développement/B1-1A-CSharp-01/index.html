    B1 1A CSharp 01

    📌 Séance 1 : Découverte de l’environnement et premiers pas en C#

    Objectifs pédagogiques : ✅ Comprendre l’écosystème .NET et son utilitaire en ligne de commande (dotnet CLI). ✅ Configurer Visual Studio Code pour le développement C#. ✅ Écrire, compiler et exécuter un premier programme en C#. ✅ Identifier les pièges courants pour les débutants.

    **📚 Partie Cours **

    **🔹 1. Introduction à .NET et C# **

    Support : Présentation orale + schémas au tableau (ou slides si disponible).

    1.1 Qu’est-ce que .NET ?

    • .NET est un framework (cadre de développement) créé par Microsoft pour développer des applications.

      • Historique rapide :
        • .NET Framework (2002) : Ancienne version, liée à Windows.
        • .NET Core (2016) : Version open-source, multiplateforme (Windows, Linux, macOS).
        • .NET 5+ (2020) : Fusion de .NET Core et .NET Framework. Nous utilisons .NET 8 ou 9 en 2026.
      • Pourquoi .NET ? :
        • Multiplateforme (fonctionne sur Ubuntu 26.04).
        • Performant, moderne, et largement utilisé en entreprise.

    • C# :

      • Langage de programmation orienté objet (POO) conçu pour .NET.
      • Syntax proche du Java ou du C++ (mais plus simple pour les débutants).

    Analogie :

    ".NET est comme un chantier de construction : il fournit tous les outils (bibliothèques, compilateur) pour construire une maison (ton application). C# est le plan de la maison que tu écris pour dire comment la construire."

    1.2 Présentation de la dotnet CLI

    Outil clé : dotnet est l’interface en ligne de commande pour gérer les projets .NET.

    Commande Description Exemple
    dotnet new Crée un nouveau projet dotnet new console -n MonProjet
    dotnet run Compile et exécute le projet dotnet run
    dotnet build Compile le projet (sans exécuter) dotnet build
    dotnet --version Affiche la version de .NET installée dotnet --version

    Démonstration live : 1. Ouvrir un terminal sous Ubuntu. 2. Vérifier que .NET est installé : 

    dotnet --version
    → Doit afficher une version (ex: 8.0.100). 3. Créer un nouveau projet console : 
    dotnet new console -n HelloBTS
    4. Se déplacer dans le dossier : 
    cd HelloBTS
    5. Exécuter le projet : 
    dotnet run
    → Affiche Hello, World!.

    Piège à éviter : - Erreur "commande introuvable" : Si dotnet n’est pas reconnu, il faut ajouter le chemin de .NET au PATH (normalement déjà fait sous Ubuntu 26.04 avec l’installation par snap ou apt).

    1.3 Structure d’un projet C#

    Contenu du dossier HelloBTS : 

    HelloBTS/
├── Program.cs       # Code source principal
├── HelloBTS.csproj  # Fichier de configuration du projet
└── obj/             # Dossier généré par la compilation (à ignorer)

    • HelloBTS.csproj : Fichier XML qui définit les dépendances et les paramètres du projet. Exemple : 

      <Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net8.0</TargetFramework>
  </PropertyGroup>
</Project>

    • Program.cs : Fichier principal contenant le code C#. Contenu par défaut : 

      // Voir https://aka.ms/new-console-template pour plus d'informations
Console.WriteLine("Hello, World!");

      • Console.WriteLine() : Affiche du texte dans la console suivi d’un saut de ligne.
      • Console.Write() : Affiche du texte sans saut de ligne.

    Modification du code : Remplacer Console.WriteLine("Hello, World!"); par : 

    Console.WriteLine("Bonjour BTS SIO !");
Console.WriteLine("Nous sommes en 2026.");

    Exécution : 

    dotnet run
    → Affiche : 
    Bonjour BTS SIO !
Nous sommes en 2026.

    1.4 Configuration de Visual Studio Code

    Objectif : Préparer VS Code pour coder en C# efficacement.

    1.4.1 Installation des extensions
    1. Ouvrir VS Code.
    2. Aller dans l’onglet Extensions (icône en forme de cube à gauche).
    3. Rechercher et installer :
      • C# (par Microsoft, id: ms-dotnettools.csharp) → Support du langage C# (coloration syntaxique, autocomplétion).
      • Code Runner (par Jun Han) → Permet d’exécuter rapidement du code (optionnel mais utile).
      • NuGet Package Manager (pour gérer les dépendances, optionnel pour ce cours).
    1.4.2 Ouvrir un projet dans VS Code
    1. Dans VS Code, cliquer sur Fichier > Ouvrir le dossier... et sélectionner HelloBTS.
    2. Le dossier s’affiche dans l’explorateur de fichiers (à gauche).
    3. Ouvrir Program.cs pour éditer le code.
    1.4.3 Exécuter le code depuis VS Code
    • Méthode 1 : Utiliser le terminal intégré.
      1. Ouvrir le terminal dans VS Code (`Ctrl + ``).
      2. Taper : 
        dotnet run
    • Méthode 2 (si Code Runner est installé) :
      1. Ouvrir Program.cs.
      2. Cliquer sur le bouton ▶️ Run Code en haut à droite du fichier. → Le code s’exécute dans le terminal intégré.

    Piège à éviter : - Problème de permissions : Si dotnet run ne fonctionne pas, vérifier que le terminal est bien dans le bon dossier (cd HelloBTS). - Extensions non chargées : Redémarrer VS Code si les fonctionnalités C# (autocomplétion) ne s’affichent pas.

    1.4.4 Personnalisation de VS Code
    • Thème : Choisir un thème clair/sombre (Fichier > Préférences > Thème > Couleur).
    • Police : Augmenter la taille de la police pour la lisibilité (Fichier > Préférences > Paramètres > Editor: Font Size).
    • Raccourcis utiles :
      • Ctrl + S : Sauvegarder.
      • Ctrl + F : Rechercher dans le fichier.
      • Ctrl + D : Sélectionner le mot sous le curseur (pour renommer rapidement).

    🔹 2. Éléments de base d’un programme C#

    2.1 La méthode Main

    • Point d’entrée du programme : toute application C# commence par exécuter la méthode Main.
    • Syntax : 
      using System; // Nécessaire pour utiliser Console

class Program {
    static void Main(string[] args) {
        // Code à exécuter
        Console.WriteLine("Ceci est exécuté en premier !");
    }
}
      • using System; : Importe le namespace System (contient Console).
      • static void Main() : Méthode principale (doit être static et void).
      • string[] args : Paramètres de ligne de commande (optionnel pour ce cours).

    Exemple complet : 

    using System;

class Program {
    static void Main() {
        Console.WriteLine("Quel est ton prénom ?");
        string prenom = Console.ReadLine(); // Lit une ligne saisie par l'utilisateur
        Console.WriteLine($"Bonjour, {prenom} !"); // Interpolation de chaîne ($)
    }
}

    Explication : - Console.ReadLine() : Attend une entrée utilisateur et retourne une chaîne de caractères (string). - Interpolation de chaîne : $"Bonjour, {prenom} !" permet d’insérer la valeur de prenom dans la chaîne.

    Pièges à éviter : - Oublier using System; → Erreur : The name 'Console' does not exist in the current context. - Oublier le ; à la fin des instructions → Erreur de syntaxe. - Confondre = (affectation) et == (comparaison).

    🔹 3. Récapitulatif et questions

    Résumé : - .NET est un framework multiplateforme pour développer des applications. - dotnet CLI permet de créer, compiler et exécuter des projets. - VS Code + extensions C# et Code Runner = environnement de développement prêt. - Un programme C# commence par Main() et utilise Console pour les entrées/sorties.

    Questions pour vérifier la compréhension : 1. À quoi sert la commande dotnet new console ? 2. Quel fichier contient le code principal d’un projet C# ? 3. Que fait Console.WriteLine() ? 4. Pourquoi faut-il ajouter using System; ?

    💻 Partie TP

    Objectif : Mettre en pratique les notions du cours en créant et modifiant des programmes simples.

    📌 TP 1 : Installation et "Hello World"

    Compétences visées : - Créer un projet C# avec dotnet CLI. - Modifier et exécuter un programme simple. - Utiliser VS Code pour éditer du code.

    🔹 Énoncé

    1. Créer un nouveau projet :

      • Ouvrir un terminal.
      • Créer un projet nommé TP1_HelloWorld avec la commande dotnet new console -n TP1_HelloWorld.
      • Se déplacer dans le dossier du projet (cd TP1_HelloWorld).

    2. Ouvrir le projet dans VS Code :

      • Lancer VS Code depuis le terminal : 
        code .
      • Ou ouvrir VS Code manuellement et sélectionner le dossier TP1_HelloWorld.

    3. Modifier le programme :

      • Ouvrir le fichier Program.cs.
      • Remplacer le contenu par : 
        using System;

class Program {
    static void Main() {
        Console.WriteLine("Bonjour, je m'appelle [Ton Prénom] [Ton Nom] !");
        Console.WriteLine("Je suis étudiant en BTS SIO à [Nom de ton établissement].");
    }
}
      • Remplacer [Ton Prénom], [Ton Nom], et [Nom de ton établissement] par tes informations.

    4. Exécuter le programme :

      • Dans le terminal intégré de VS Code, taper : 
        dotnet run
      • Vérifier que le message s’affiche correctement.

    5. Aller plus loin (optionnel) :

      • Ajouter une ligne pour afficher l’année en cours (2026) : 
        Console.WriteLine("Nous sommes en 2026.");

    Critères de réussite : - [ ] Le projet est créé avec dotnet new console. - [ ] Le code est modifié et personnalisé. - [ ] Le programme s’exécute sans erreur et affiche les messages attendus.

    📌 TP 2 : Calculatrice simple

    Compétences visées : - Utiliser Console.ReadLine() pour lire des entrées utilisateur. - Convertir des chaînes en nombres (int.Parse). - Effectuer des opérations arithmétiques de base.

    🔹 Énoncé

    Écrire un programme qui : 1. Demande à l’utilisateur de saisir deux nombres entiers. 2. Calcule et affiche : - La somme des deux nombres. - La différence (premier nombre - deuxième nombre). - Le produit des deux nombres. - Le quotient (division entière) du premier nombre par le deuxième.

    Exemple d’exécution : 

    Saisissez le premier nombre : 10
Saisissez le deuxième nombre : 3
Somme : 13
Différence : 7
Produit : 30
Quotient : 3

    🔹 Étapes détaillées

    1. Créer un nouveau projet :

      • Dans un nouveau terminal, créer un projet TP2_Calculatrice : 
        dotnet new console -n TP2_Calculatrice
cd TP2_Calculatrice
code .

    2. Écrire le code :

      • Dans Program.cs, remplacer le contenu par : 
        using System;

class Program {
    static void Main() {
        // 1. Demander les deux nombres
        Console.WriteLine("Saisissez le premier nombre :");
        string input1 = Console.ReadLine();
        int nombre1 = int.Parse(input1);

        Console.WriteLine("Saisissez le deuxième nombre :");
        string input2 = Console.ReadLine();
        int nombre2 = int.Parse(input2);

        // 2. Calculer les opérations
        int somme = nombre1 + nombre2;
        int difference = nombre1 - nombre2;
        int produit = nombre1 * nombre2;
        int quotient = nombre1 / nombre2; // Division entière

        // 3. Afficher les résultats
        Console.WriteLine($"Somme : {somme}");
        Console.WriteLine($"Différence : {difference}");
        Console.WriteLine($"Produit : {produit}");
        Console.WriteLine($"Quotient : {quotient}");
    }
}

    3. Tester le programme :

      • Exécuter avec dotnet run.
      • Vérifier que les calculs sont corrects pour différents jeux de nombres (ex : 10 et 3, 5 et 0, -2 et 4).

    Pièges à éviter : - Erreur de conversion : Si l’utilisateur saisit un texte au lieu d’un nombre → FormatException. - Solution : Ajouter une gestion d’erreur (hors scope pour ce TP, mais à mentionner pour les étudiants avancés). - Division par zéro : Si nombre2 = 0, le programme plantera. - Solution : Vérifier que nombre2 != 0 avant la division (à faire en bonus).

    🔹 Bonus (pour les rapides)

    1. Gérer la division par zéro :

      • Modifier le code pour afficher un message d’erreur si nombre2 = 0

    2. Afficher le reste de la division :

      • Utiliser l’opérateur % (modulo) pour afficher le reste

    📌 Consignes générales pour les TP

    1. Travail individuel : Chaque étudiant doit réaliser les TP sur sa machine.
    2. Nommage des projets :
      • Utiliser le format TPX_NomDuProjet (ex : TP1_HelloWorld).
      • Interdiction des espaces ou caractères spéciaux dans les noms de projets.
    3. Sauvegarde :
      • Sauvegarder régulièrement (Ctrl + S).
      • À la fin du TP, compresser le dossier du projet et le nommer TPX_Nom_Prénom.zip (ex : TP1_HelloWorld_Dupont_Jean.zip).
