    B1 1A CSharp 05 Tableaux et listes

    📚 Tableaux et listes en C#

    (Fiche synthèse : les notions ont déjà été manipulées en TP)

    1. Tableau vs liste : quoi choisir ?

    Tableau T[] Liste List<T>
    Taille Fixe Dynamique
    Nombre d’éléments Length Count
    Index valides 0 à Length - 1 0 à Count - 1
    Tri Array.Sort(tab) liste.Sort()
    À utiliser quand… Taille connue et stable Taille variable (saisies…)

    2. Création et manipulation

    int[] tableau = { 5, 10, 15 };                     // Tableau
List<string> liste = new List<string> { "a", "b" }; // Liste

tableau[0] = 7;          // Accès / modification par index
liste.Add("c");          // Ajout à la fin
liste.Remove("a");       // Suppression 1ʳᵉ occurrence (retourne bool)
liste.RemoveAt(0);       // Suppression par index
liste.Insert(1, "z");    // Insertion à une position
liste.Contains("b");    // Présence ? (bool)
liste.IndexOf("b");    // Position ou -1 si absent
liste.Sort();            // Tri croissant sur place
liste.Reverse();         // Inversion sur place
liste.Clear();           // Vidage

    3. Parcours

    // Lecture simple → foreach (recommandé)
foreach (int n in tableau) { Console.WriteLine(n); }

// Index nécessaire ou modification → for
for (int i = 0; i < liste.Count; i++) {
    Console.WriteLine($"{i + 1}. {liste[i]}");
    // liste[i] = ...  // modification possible seulement avec for
}

    4. Calculs classiques (accumulateurs)

    double somme = 0;
double min = tableau[0], max = tableau[0];   // ⚠️ initialiser avec le 1ᵉʳ élément, pas 0
foreach (double n in tableau) {
    somme += n;
    if (n < min) min = n;
    if (n > max) max = n;
}
double moyenne = somme / tableau.Length;    // cast si entier : (double)somme / nb

    5. Les 4 pièges à connaître

    Piège Symptôme Règle
    tab[tab.Length] IndexOutOfRangeException Dernier index = Length - 1
    liste.Length / tab.Count Erreur compilation Tableau = Length, liste = Count
    min = 0 Min faux si tout positif Initialiser avec le premier élément
    Modifier dans un foreach Erreur compilation Parcours en modification → for
    Accès à liste[0] si vide Exception Vérifier Count > 0 avant l’accès
