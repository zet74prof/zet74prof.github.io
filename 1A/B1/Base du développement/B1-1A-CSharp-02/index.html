    B1 1A CSharp 02

    📌 Séance 2 : Variables, types de données et opérateurs

    Objectifs pédagogiques : ✅ Comprendre les types de données primaires en C# (int, double, string, bool, char). ✅ Déclarer et utiliser des variables. ✅ Maîtriser les opérateurs arithmétiques (+, -, *, /, %) et logiques (&&, ||, !). ✅ Effectuer des conversions de types (implicites et explicites). ✅ Utiliser Console.ReadLine() et les conversions pour interagir avec l’utilisateur.

    📚 Partie Cours

    📚 0. Gestion des chaînes de caractères (string) en C#

    🔹 0.1. Déclaration et initialisation

    Une chaîne de caractères (string) est une séquence de caractères Unicode.

    Syntaxe de déclaration :
    string nom = "Étienne";          // Avec des guillemets doubles
string texte = "Bonjour BTS SIO"; // Espaces autorisés
string vide = "";                // Chaîne vide
string nullString = null;        // Chaîne nulle (pas de valeur)

    Remarques : - Utiliser toujours des guillemets doubles (") pour les chaînes. - Une chaîne vide ("") est différente d’une chaîne nulle (null). - Immutabilité : Toute modification d’une chaîne crée une nouvelle chaîne en mémoire. Exemple : 

    string texte = "Bonjour";
texte = texte + " !"; // Crée une nouvelle chaîne "Bonjour !"

    🔹 0.2. Concaténation de chaînes

    La concaténation consiste à assembler plusieurs chaînes en une seule.

    L’opérateur + permet de concaténer des chaînes ou de mélanger chaînes et autres types (qui sont convertis en chaîne automatiquement).

    Exemples : 

    string prenom = "Étienne";
string nom = "BUFFET";
string nomComplet = prenom + " " + nom; // "Étienne BUFFET"

// Mélange avec d'autres types
int age = 25;
string presentation = "J'ai " + age + " ans."; // "J'ai 25 ans."

    Piège à éviter : - Concaténation de nombres : Si les deux opérandes sont des nombres, + effectue une addition arithmétique. 

    int a = 10;
int b = 20;
string resultat = a + b; // ❌ Erreur : resultat est un int (30), pas un string
string resultatCorrect = a.ToString() + b.ToString(); // "1020"

    🔹 0.3. Interpolation de chaînes ($)

    L’interpolation de chaînes permet d’insérer directement des expressions dans une chaîne, en utilisant le préfixe $ avant les guillemets.

    Syntaxe :
    string message = $"{variable} texte {expression}";

    Exemples : 

    string prenom = "Étienne";
int age = 25;
string message = $"Je m'appelle {prenom} et j'ai {age} ans.";
// Résultat : "Je m'appelle Étienne et j'ai 25 ans."

// Avec des expressions
int a = 10, b = 20;
string calcul = $"{a} + {b} = {a + b}"; // "10 + 20 = 30"

    Avantages : - Plus lisible que la concaténation avec +. - Moins sujet aux erreurs (pas besoin de convertir manuellement les types).

    Piège à éviter : - Oublier le $ devant les guillemets : 

    string message = "{prenom} a {age} ans."; // ❌ Affiche "{prenom} a {age} ans." littéralement

    🔹 0.4. Méthodes et propriétés utiles pour les string

    Méthode/Propriété Description Exemple Résultat
    Length Retourne la longueur de la chaîne. "Bonjour".Length 7
    ToUpper() Convertit en majuscules. "bonjour".ToUpper() "BONJOUR"
    ToLower() Convertit en minuscules. "BONJOUR".ToLower() "bonjour"
    Substring(start) Extrait une sous-chaîne à partir de start. "Bonjour".Substring(3) "jour"
    Substring(start, length) Extrait length caractères à partir de start. "Bonjour".Substring(0, 4) "Bonj"
    IndexOf(char) Retourne l’index de la première occurrence d’un caractère. "Bonjour".IndexOf('o') 1 (index de 'o')
    IndexOf(string) Retourne l’index de la première occurrence d’une sous-chaîne. "Bonjour".IndexOf("jour") 3
    Contains(string) Vérifie si la chaîne contient une sous-chaîne. "Bonjour".Contains("jour") true
    StartsWith(string) Vérifie si la chaîne commence par une sous-chaîne. "Bonjour".StartsWith("Bon") true
    EndsWith(string) Vérifie si la chaîne finit par une sous-chaîne. "Bonjour".EndsWith("jour") true
    Replace(old, new) Remplace toutes les occurrences de old par new. "Bonjour".Replace("o", "a") "Banjaur"
    Trim() Supprime les espaces en début et fin de chaîne. " Bonjour ".Trim() "Bonjour"
    TrimStart() Supprime les espaces au début. " Bonjour".TrimStart() "Bonjour"
    TrimEnd() Supprime les espaces à la fin. "Bonjour ".TrimEnd() "Bonjour"
    Split(char) Découpe la chaîne en un tableau, selon un séparateur. "a,b,c".Split(',') ["a", "b", "c"]
    IsNullOrEmpty() Vérifie si la chaîne est nulle ou vide. string.IsNullOrEmpty("") true
    IsNullOrWhiteSpace() Vérifie si la chaîne est nulle, vide ou composée d’espaces. string.IsNullOrWhiteSpace(" ") true

    Exemples combinés : 

    string texte = "   Bonjour BTS SIO   ";
// Nettoyage + majuscules
string texteNettoye = texte.Trim().ToUpper(); // "BONJOUR BTS SIO"

// Remplacement
string texteModifie = texte.Replace("BTS", "BTS SIO 2"); // "   Bonjour BTS SIO 2   "

// Extraction
string sousTexte = texte.Substring(8, 3); // "BTS" (à partir de l'index 8, 3 caractères)

    🔹 0.5. Comparaison de chaînes

    En C#, les chaînes peuvent être comparées avec les opérateurs ==, !=, <, >, etc., mais attention : - La comparaison est sensible à la casse par défaut ("A" != "a"). - Pour une comparaison insensible à la casse, utiliser String.Equals avec StringComparison.OrdinalIgnoreCase.

    0.5.1 Opérateurs de comparaison
    Opérateur Description Exemple Résultat
    == Égalité "a" == "a" true
    != Inégalité "a" != "b" true
    < Inférieur (comparaison lexicographique) "a" < "b" true
    > Supérieur "b" > "a" true

    Exemple : 

    string a = "apple";
string b = "banana";
Console.WriteLine(a < b); // true ("apple" vient avant "banana" dans l'ordre lexicographique)

    Remarque : - La comparaison lexicographique utilise l’ordre Unicode (ex: 'A' < 'a' car 'A' a un code Unicode plus petit).

    0.5.2 Méthode String.Equals

    Pour une comparaison précise (avec ou sans sensibilité à la casse) : 

    string a = "Bonjour";
string b = "bonjour";

// Sensible à la casse (par défaut)
bool egal1 = a.Equals(b); // false

// Insensible à la casse
bool egal2 = a.Equals(b, StringComparison.OrdinalIgnoreCase); // true

    🔹 0.6. Chaînes verbatim (@)

    Les chaînes verbatim (préfixe @) permettent d’écrire des chaînes sans échapper les caractères spéciaux (comme \n, \t, ou \"). Elles sont utiles pour : - Les chemins de fichiers (ex: @"C:\Dossier\Fichier.txt"). - Les expressions régulières. - Les chaînes multi-lignes.

    Exemple : 

    // Sans @, il faut échapper les backslashes
string chemin1 = "C:\\Dossier\\Fichier.txt";

// Avec @, pas besoin d'échapper
string chemin2 = @"C:\Dossier\Fichier.txt";

// Chaîne multi-lignes
string texte = @"Ceci est une ligne.
                 Ceci est une autre ligne.";
Console.WriteLine(texte);
// Affiche :
// Ceci est une ligne.
//                  Ceci est une autre ligne.

    Remarque : - Les guillemets doubles doivent être doublés dans une chaîne verbatim : 

    string citation = @"Il a dit : ""Bonjour"" !"; // Affiche : Il a dit : "Bonjour" !

    🔹 0.7. Chaînes brutes (""" en C# 11+)

    Depuis C# 11 (2022), il est possible d’utiliser des chaînes brutes (raw string literals) avec trois guillemets ("""). Elles permettent : - D’écrire des chaînes multi-lignes sans utiliser @ ou \n. - D’inclure n’importe quel caractère (y compris des guillemets ou des accolades) sans échappement.

    Exemple : 

    string json = """
    {
        "nom": "Étienne",
        "age": 25,
        "ville": "Paris"
    }
    """;
Console.WriteLine(json);
    → Affiche exactement le JSON, y compris les sauts de ligne et les indentations.

    Avantages par rapport à @ : - Pas besoin de doubler les guillemets. - Meilleure lisibilité pour les textes longs (ex : requêtes SQL, JSON, XML).

    🔹 0.8. Pièges courants avec les string

    Piège Exemple Solution
    Concaténation de nombres string s = 10 + 20; → s vaut 30 (int) string s = (10).ToString() + (20).ToString();
    Comparaison sensible à la casse "A" == "a" → false Utiliser Equals avec StringComparison.OrdinalIgnoreCase.
    Chaîne nulle vs chaîne vide string s = null; vs string s = ""; Toujours vérifier string.IsNullOrEmpty(s).
    Modification d’une chaîne s[0] = 'B'; → ❌ Erreur (immutable) Créer une nouvelle chaîne : s = "B" + s.Substring(1);.
    Index hors limites "abc".Substring(5) → ❌ ArgumentOutOfRangeException Vérifier s.Length avant d’extraire.
    Utilisation de == avec null if (s == null) → ✅ OK, mais if (s.Length == 0) → ❌ NullReferenceException si s est null Toujours vérifier s != null avant d’accéder à s.Length.

    📌 Bonnes pratiques

    1. Préférer l’interpolation ($"...") à la concaténation (+) pour la lisibilité.
    2. Utiliser String.IsNullOrEmpty pour vérifier si une chaîne est vide ou nulle.
    3. Éviter les chaînes trop longues : Si une chaîne dépasse 1000 caractères, envisager de la stocker dans un fichier ou une base de données.
    4. Pour les chemins de fichiers : Toujours utiliser @ ou Path.Combine : 
      string chemin = Path.Combine("C:", "Dossier", "Fichier.txt"); // Plus sûr que la concaténation
    5. Pour les comparaisons :
      • Utiliser String.Equals pour une comparaison explicite.
      • Éviter == avec des chaînes nulles (risque de NullReferenceException).

    🔹 1. Les variables et les types de données

    1.1 Pourquoi utiliser des variables ?

    • Une variable est un conteneur qui stocke une valeur en mémoire.
    • Elle a :
      • Un nom (identifiant).
      • Un type (détermine le genre de données qu’elle peut contenir).
      • Une valeur (contenu).

    Analogie :

    "Une variable est comme une boîte étiquetée : - L’étiquette = le nom de la variable (ex: age). - La taille de la boîte = le type (ex: int pour un nombre entier). - Le contenu = la valeur (ex: 20)."

    1.2 Types de données primaires

    Voici les types les plus utilisés en C# pour commencer :

    Type Description Exemple Taille (octets) Plage de valeurs
    int Entier (nombres sans décimales) int age = 20; 4 -2,147,483,648 à 2,147,483,647
    long Entier long long population = 8000000000; 8 -9,223,372,036,854,775,808 à 9,223,372,036,854,775,807
    double Nombre à virgule (précision double) double prix = 19.99; 8 ±5.0 × 10-324 à ±1.7 × 10308
    float Nombre à virgule (précision simple) float temperature = 36.6f; 4 ±1.5 × 10-45 à ±3.4 × 1038
    decimal Nombre décimal (précision financière) decimal solde = 1000.50m; 16 ±1.0 × 10-28 à ±7.9 × 1028
    string Chaîne de caractères string nom = "Étienne"; Variable Limité par la mémoire
    char Caractère unique char lettre = 'A'; 2 Un seul caractère Unicode
    bool Booléen (vrai/faux) bool estMajeur = true; 1 true ou false

    Remarques : - double est plus précis que float. - decimal est idéal pour les calculs financiers (évite les erreurs d’arrondi).

    Littéraux : - Pour les nombres à virgule flottante, on utilise f ou F pour le type float et d ou D ou rien pour le type double. - Pour les nombres décimaux, on utilise m ou M. Exemple : 

    float unFloat = 3.14f;
double unDouble = 3.14159; // double par défaut
double unAutreDouble = 3.14159d;
decimal unEntier = 1000.50m;

    1.3 Déclaration et initialisation des variables

    Syntaxe : 

    type nomVariable = valeur;
    Exemples : 
    int age = 20;
double prix = 19.99;
string prenom = "Alice";
bool estEtudiant = true;
char note = 'A';

    Bonnes pratiques : - Nommage : - Utiliser des noms explicites : nombreEtudiants au lieu de x. - Convention PascalCase pour les noms de variables (ex: monAge, nomUtilisateur). - Éviter les noms génériques comme data, temp, var1. - Initialisation : - Toujours initialiser une variable avant de l’utiliser (sinon erreur de compilation).

    Piège à éviter : - Variable non initialisée : 

    int nombre; // Déclaration sans initialisation
Console.WriteLine(nombre); // ❌ Erreur : "Use of unassigned local variable"

    1.4 Constantes

    • Une constante est une variable dont la valeur ne peut pas changer après initialisation.
    • Syntaxe : 
      const type NOM_CONSTANTE = valeur;
    • Exemple : 
      const double PI = 3.14159;
const string NOM_BTS = "BTS SIO";
    • Convention : Utiliser des MAJUSCULES pour les noms de constantes.

    🔹 2. Opérateurs

    2.1 Opérateurs arithmétiques

    Opérateur Nom Exemple Résultat
    + Addition 5 + 3 8
    - Soustraction 5 - 3 2
    * Multiplication 5 * 3 15
    / Division 5 / 2 2 (division entière)
    % Modulo (reste) 5 % 2 1

    Exemple complet : 

    int a = 10;
int b = 3;
Console.WriteLine($"Addition : {a + b}");       // 13
Console.WriteLine($"Soustraction : {a - b}");  // 7
Console.WriteLine($"Multiplication : {a * b}"); // 30
Console.WriteLine($"Division : {a / b}");       // 3 (division entière)
Console.WriteLine($"Reste : {a % b}");          // 1

    Piège à éviter : - Division entière : 5 / 2 donne 2 (et non 2.5). - Solution : Utiliser double pour obtenir un résultat décimal : 

    double resultat = 5.0 / 2; // 2.5

    2.2 Opérateurs d’affectation composés

    Opérateur Équivalent Exemple Résultat
    += a = a + b a += 3 a = a + 3
    -= a = a - b a -= 3 a = a - 3
    *= a = a * b a *= 3 a = a * 3
    /= a = a / b a /= 3 a = a / 3
    %= a = a % b a %= 3 a = a % 3

    Exemple : 

    int compteur = 0;
compteur += 5; // compteur = 5
compteur *= 2; // compteur = 10

    2.3 Opérateurs de comparaison

    Opérateur Nom Exemple Résultat
    == Égal à 5 == 3 false
    != Différent de 5 != 3 true
    > Supérieur à 5 > 3 true
    < Inférieur à 5 < 3 false
    >= Supérieur ou égal 5 >= 3 true
    <= Inférieur ou égal 5 <= 3 false

    Exemple : 

    int age = 20;
bool estMajeur = age >= 18; // true
Console.WriteLine($"Est majeur ? {estMajeur}");

    2.4 📚 Opérateurs booléens et logique booléenne

    Opérateur Nom Exemple Résultat
    && ET logique true && false false
    || OU logique true || false true
    ! NON logique !true false

    Exemple : 

    bool a = true;
bool b = false;
Console.WriteLine($"ET : {a && b}"); // false
Console.WriteLine($"OU : {a || b}"); // true
Console.WriteLine($"NON : {!a}");   // false

    Piège à éviter : - Confondre = (affectation) et == (comparaison) : 

    if (age = 18) { ... } // ❌ Erreur : affecte 18 à age, puis évalue age (toujours vrai si age != 0)
if (age == 18) { ... } // ✅ Correct

    🔹 Rappel : Algèbre de Boole et opérateurs en C#

    2.4.1 Définitions formelles
    • Ensemble de base : {Vrai (true), Faux (false)} noté {V, F}.
    • Opérateurs :
      • Négation (!) : Opérateur unaire (1 opérande).
        • !V = F, !F = V.
      • ET (&) : Opérateur binaire (2 opérandes).
        • V & V = V, V & F = F, F & V = F, F & F = F.
      • OU (|) : Opérateur binaire.
        • V | V = V, V | F = V, F | V = V, F | F = F.
      • OU Exclusif (^) : Opérateur binaire.
        • V ^ V = F, V ^ F = V, F ^ V = V, F ^ F = F.
        • Interprétation : "L’un ou l’autre, mais pas les deux".

    Table de vérité complète (à afficher au tableau ou en slide) :

    p q !p p & q p | q p ^ q
    V V F V V F
    V F F F V V
    F V V F V V
    F F V F F F
    2.4.2 Différence entre &/| et &&/||
    Opérateur Nom Évaluation Cas d’usage
    & ET logique Toujours évalue les 2 opérandes Opérations bit à bit (rare en logique booléenne pure).
    && ET conditionnel Court-circuit : si p est false, q n’est pas évalué Recommandé pour les conditions (ex: if (x > 0 && x < 10)).
    | OU logique Toujours évalue les 2 opérandes Opérations bit à bit.
    || OU conditionnel Court-circuit : si p est true, q n’est pas évalué Recommandé pour les conditions (ex: if (x == 0 || y == 0)).

    Exemple de court-circuit : 

    int x = 0;
bool resultat = (x != 0) && (10 / x > 5); // Pas d'erreur : si x == 0, (10 / x) n'est pas évalué !
Console.WriteLine(resultat); // false
    → Si on avait utilisé & au lieu de &&, le programme aurait planté à cause de la division par zéro.

    ⚠️ Piège à éviter : - Utiliser & ou | à la place de && ou || dans des conditions peut entraîner des erreurs d’exécution (ex : accès à un objet null). - Règle : Toujours utiliser && et || pour les conditions logiques en C#.

    2.4.3 Priorité des opérateurs booléens

    Ordre de priorité (du plus prioritaire au moins prioritaire) : 1. ! (négation) 2. & (ET logique) 3. ^ (OU exclusif) 4. | (OU logique) 5. && (ET conditionnel) 6. || (OU conditionnel)

    Exemple : 

    bool p = true, q = false, r = true;
bool resultat = !p & q || r; // Équivaut à : ((!p) & q) || r
// Calcul :
// 1. !p → false
// 2. false & q → false
// 3. false || r → true
Console.WriteLine(resultat); // true

    Astuce : Utiliser des parenthèses pour clarifier l’ordre d’évaluation : 

    bool resultat = (!(p & q)) || r; // Plus lisible

    2.4.4 Exemples concrets en C#

    Cas 1 : Validation d’un mot de passe 

    string motDePasse = "Azerty123!";
bool aMajuscule = motDePasse.Any(char.IsUpper); // true si au moins une majuscule
bool aChiffre = motDePasse.Any(char.IsDigit);     // true si au moins un chiffre
bool aSymbole = motDePasse.Any(char.IsSymbol);   // true si au moins un symbole

bool estValide = aMajuscule && aChiffre && aSymbole; // ET logique
Console.WriteLine($"Mot de passe valide ? {estValide}"); // true

    Cas 2 : Jeu "Pierre-Feuille-Ciseaux" 

    string choixJoueur = "pierre";
string choixOrdi = "feuille";

bool joueurGagne = (choixJoueur == "pierre" && choixOrdi == "ciseaux") ||
                   (choixJoueur == "feuille" && choixOrdi == "pierre") ||
                   (choixJoueur == "ciseaux" && choixOrdi == "feuille");
Console.WriteLine($"Le joueur gagne ? {joueurGagne}"); // false

    Cas 3 : Détection d’une année bissextile 

    int annee = 2024;
bool estBissextile = (annee % 4 == 0 && annee % 100 != 0) || (annee % 400 == 0);
Console.WriteLine($"{annee} est bissextile ? {estBissextile}"); // true

    🔹 3. Conversions de types

    3.1 Conversions implicites

    • Effectuées automatiquement par C# lorsque la conversion est sûre (pas de perte de données).
    • Exemples : 
      int a = 10;
double b = a; // Conversion implicite int → double (sécurisée)
Console.WriteLine(b); // 10.0

    3.2 Conversions explicites (Cast)

    • Nécessaires lorsque la conversion peut entraîner une perte de données (ex: double → int).
    • Syntaxe : 
      type cible = (type)valeur;
    • Exemple : 
      double x = 10.5;
int y = (int)x; // Cast explicite (perte de la partie décimale)
Console.WriteLine(y); // 10

    Piège à éviter : - Perte de données : 

    int nombre = 1000000000;
short petitNombre = (short)nombre; // ❌ Dépassement de capacité (short max = 32767)
Console.WriteLine(petitNombre); // -29496 (valeur incorrecte)

    3.3 Méthodes de conversion utiles

    Méthode Description Exemple
    ToString() Convertit une valeur en string int age = 20; string ageTexte = age.ToString();
    Parse() Convertit une string en type spécifié string texte = "25"; int nombre = int.Parse(texte);
    Convert.ToType() Convertit une valeur en un type spécifié string texte = "3.14"; double nombre = Convert.ToDouble(texte);
    TryParse() Essaye de convertir une string (sans lever d’erreur) bool succes = int.TryParse(texte, out int nombre);

    Exemple avec TryParse (recommandé pour éviter les erreurs) : 

    string input = "25";
if (int.TryParse(input, out int nombre)) {
    Console.WriteLine($"Conversion réussie : {nombre}");
} else {
    Console.WriteLine("La saisie n'est pas un nombre entier.");
}

    Pourquoi TryParse ? : - int.Parse() lève une exception (FormatException) si la chaîne n’est pas un nombre. - TryParse retourne false et ne lève pas d’exception (plus sûr pour les entrées utilisateur).
