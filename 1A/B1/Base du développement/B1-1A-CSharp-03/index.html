    📌 Etape 3 : Structures conditionnelles (if, else, switch)

    Objectifs pédagogiques : ✅ Comprendre le rôle des structures conditionnelles en programmation. ✅ Maîtriser l’utilisation de if, else if, else pour des choix multiples. ✅ Utiliser l’opérateur ternaire (?:) pour des conditions simples. ✅ Appliquer switch pour des comparaisons de valeurs discrètes. ✅ Combiner les structures conditionnelles avec les opérateurs booléens (&&, ||, !). ✅ Identifier les pièges courants (ex : conditions redondantes, oublis de break dans switch).

    📚 Partie Cours

    🔹 1. Introduction aux structures conditionnelles

    1.1 Pourquoi utiliser des conditions ?

    • En programmation, un programme doit souvent prendre des décisions en fonction de :
      • Données saisies par l’utilisateur (ex : âge, choix dans un menu).
      • Résultats de calculs (ex : une note est-elle supérieure à 10 ?).
      • État du programme (ex : un jeu est-il terminé ?).

    Analogie :

    "Une structure conditionnelle est comme un panneau de signalisation dans un programme : - if = \"Si tu vois un feu rouge, arrête-toi.\" - else = \"Sinon, continue.\" - switch = \"Selon la direction que tu prends, suis le bon chemin.\""

    1.2 Syntaxe de base : if

    • Structure : 
      if (condition) {
    // Code exécuté si la condition est VRAIE (true)
}
    • Exemple : 
      int age = 20;
if (age >= 18) {
    Console.WriteLine("Tu es majeur.");
}
    • Règles :
      • La condition doit être une expression booléenne (retourne true ou false).
      • Les accolades {} sont obligatoires si le bloc contient plusieurs instructions.
      • Si le bloc ne contient qu’une seule instruction, les accolades sont optionnelles (mais déconseillées pour la lisibilité).

    Piège à éviter : - Oublier les parenthèses : 

    if age >= 18 { ... } // ❌ Erreur : il manque les parenthèses autour de la condition

    🔹 2. if/else if/else : Choix multiples

    2.1 Syntaxe

    if (condition1) {
    // Code si condition1 est vraie
}
else if (condition2) {
    // Code si condition2 est vraie (et condition1 fausse)
}
else {
    // Code si aucune condition précédente n'est vraie
}

    2.2 Exemple complet

    int note = 14;

if (note >= 16) {
    Console.WriteLine("Très bien !");
}
else if (note >= 14) {
    Console.WriteLine("Bien !");
}
else if (note >= 12) {
    Console.WriteLine("Assez bien !");
}
else if (note >= 10) {
    Console.WriteLine("Passable.");
}
else {
    Console.WriteLine("Insuffisant.");
}
// Affiche : "Bien !"

    2.3 Cas pratique : Système de notation

    Problème : Écrire un programme qui affiche la mention associée à une note sur 20.

    Note Mention
    16 ≤ note ≤ 20 Très bien
    14 ≤ note < 16 Bien
    12 ≤ note < 14 Assez bien
    10 ≤ note < 12 Passable
    note < 10 Insuffisant

    Solution : 

    int note = 15;
if (note >= 16) {
    Console.WriteLine("Très bien !");
}
else if (note >= 14) {
    Console.WriteLine("Bien !");
}
else if (note >= 12) {
    Console.WriteLine("Assez bien !");
}
else if (note >= 10) {
    Console.WriteLine("Passable.");
}
else {
    Console.WriteLine("Insuffisant.");
}

    Pièges à éviter : 1. Conditions redondantes : 

    if (note >= 10) { ... }
else if (note >= 12) { ... } // ❌ Inutile : si note >= 12, alors note >= 10 est déjà vrai
    → Toujours ordonner les conditions du plus restrictif au moins restrictif (ex : de >= 16 à < 10).

    1. Oublier le else final :
      • Si aucune condition n’est vraie, rien ne se passe (pas d’erreur, mais comportement inattendu).

    ---

    🔹 3. Opérateur ternaire (?:)

    • Syntaxe : 
      variable = (condition) ? valeurSiVrai : valeurSiFaux;
    • Exemple : 
      int age = 20;
string statut = (age >= 18) ? "Majeur" : "Mineur";
Console.WriteLine(statut); // "Majeur"
    • Avantages :
      • Plus concis qu’un if/else pour des affectations simples.
      • Lisible si bien utilisé.

    Piège à éviter : - Abuser de l’opérateur ternaire pour des logiques complexes : 

    string resultat = (x > 0) ? "Positif" : (x < 0) ? "Négatif" : "Nul"; // ✅ OK
string resultat = (x > 0) ? "Positif" : (x < 0) ? "Négatif" : (x == 0) ? "Nul" : "Erreur"; // ❌ Trop complexe
    → Préférer un if/else dans ce cas.

    ---

    🔹 4. Structure switch

    4.1 Syntaxe de base

    switch (variable) {
    case valeur1:
        // Code si variable == valeur1
        break;
    case valeur2:
        // Code si variable == valeur2
        break;
    default:
        // Code si aucune valeur ne correspond
        break;
}

    4.2 Exemple : Menu interactif

    Console.WriteLine("Choisissez une option :");
Console.WriteLine("1. Ajouter un utilisateur");
Console.WriteLine("2. Supprimer un utilisateur");
Console.WriteLine("3. Quitter");
int choix = int.Parse(Console.ReadLine());

switch (choix) {
    case 1:
        Console.WriteLine("Ajout d'un utilisateur...");
        break;
    case 2:
        Console.WriteLine("Suppression d'un utilisateur...");
        break;
    case 3:
        Console.WriteLine("Au revoir !");
        break;
    default:
        Console.WriteLine("Option invalide.");
        break;
}

    4.3 Règles et bonnes pratiques

    1. break obligatoire :

      • Sans break, le code continue d’exécuter les case suivants (comportement de "fall-through").
      • Exemple de fall-through intentionnel : 
        switch (note) {
    case 20:
    case 19:
    case 18:
        Console.WriteLine("Excellent !");
        break;
    case 17:
    case 16:
        Console.WriteLine("Très bien !");
        break;
    // ...
}
        → Ici, les notes 20, 19 et 18 affichent "Excellent !".

    2. default optionnel :

      • Si aucun case ne correspond, rien ne se passe (sauf si default est présent).

    3. Types autorisés :

      • switch fonctionne avec :
        • int, char, string, enum, et quelques autres types.
      • Pas autorisé : double, float, bool.

    Piège à éviter : - Oublier le break : 

    case 1:
    Console.WriteLine("Option 1");
    // ❌ Oubli du break → les case 2 et 3 seront aussi exécutés !
case 2:
    Console.WriteLine("Option 2");

    4.4 switch avec des string

    Exemple : 

    string couleur = "rouge";
switch (couleur.ToLower()) { // Convertir en minuscules pour éviter les problèmes de casse
    case "rouge":
        Console.WriteLine("Couleur : Rouge");
        break;
    case "vert":
        Console.WriteLine("Couleur : Vert");
        break;
    case "bleu":
        Console.WriteLine("Couleur : Bleu");
        break;
    default:
        Console.WriteLine("Couleur inconnue.");
        break;
}

    Avantages : - Plus lisible que des if/else en cascade. - Moins sujet aux erreurs (pas de risque d’oublier un break).

    ---

    🔹 5. Combinaison avec les opérateurs booléens

    Les structures conditionnelles sont souvent combinées avec des opérateurs booléens (&&, ||, !) pour des logiques complexes.

    Exemple 1 : Validation d’un utilisateur 

    string login = "etienne";
string motDePasse = "1234";
bool estAdmin = false;

if ((login == "etienne" && motDePasse == "1234") || estAdmin) {
    Console.WriteLine("Accès autorisé.");
} else {
    Console.WriteLine("Accès refusé.");
}

    Exemple 2 : Jeu "Pierre-Feuille-Ciseaux" 

    string choixJoueur = "pierre";
string choixOrdi = "feuille";

if ((choixJoueur == "pierre" && choixOrdi == "ciseaux") ||
    (choixJoueur == "feuille" && choixOrdi == "pierre") ||
    (choixJoueur == "ciseaux" && choixOrdi == "feuille")) {
    Console.WriteLine("Vous gagnez !");
} else if (choixJoueur == choixOrdi) {
    Console.WriteLine("Égalité !");
} else {
    Console.WriteLine("Vous perdez !");
}

    Piège à éviter : - Conditions trop complexes : 

    if ((x > 0 && y < 10) || (z == 5 && !flag) || (a && b && c)) { ... }
    → Découper en sous-conditions ou utiliser des variables intermédiaires : 
    bool condition1 = x > 0 && y < 10;
bool condition2 = z == 5 && !flag;
bool condition3 = a && b && c;
if (condition1 || condition2 || condition3) { ... }

    💻 Partie TP

    Objectif : Appliquer les structures conditionnelles à des problèmes concrets, avec une difficulté progressive.

    📌 TP 3-1 : Système de notation simple (Niveau : Débutant)

    Compétences visées : - Utiliser if/else if/else pour des choix multiples. - Appliquer des comparaisons numériques.

    🔹 Énoncé

    Écrire un programme qui : 1. Demande à l’utilisateur de saisir une note sur 20 (entier). 2. Affiche la mention associée selon le tableau suivant :

    Note Mention
    16 ≤ note ≤ 20 Très bien
    14 ≤ note < 16 Bien
    12 ≤ note < 14 Assez bien
    10 ≤ note < 12 Passable
    note < 10 Insuffisant

    Exemple d’exécution : 

    Saisissez une note : 15
Bien !

    🔹 Consignes détaillées

    1. Créer un projet : 

      dotnet new console -n TP3-1_Notation
cd TP3-1_Notation
code .

    2. Écrire le code :

      • Utiliser Console.ReadLine() pour lire la note.
      • Convertir la saisie en int avec int.Parse ou int.TryParse.
      • Utiliser une structure if/else if/else pour afficher la mention.

    3. Tester :

      • Vérifier avec les notes 10, 12, 14, 16, 18, 20, 5.

    🔹 Extensions pour les rapides

    1. Gestion des erreurs :

      • Utiliser int.TryParse pour éviter les plantages si l’utilisateur saisit un texte.
      • Afficher un message d’erreur si la saisie n’est pas un nombre.

    2. Ajouter des mentions personnalisées :

      • Si la note est 20, afficher "Félicitations ! Parfait !".
      • Si la note est 0, afficher "Zéro ? Vraiment ?".

    3. Boucle pour plusieurs notes :

      • Demander à l’utilisateur s’il veut saisir une autre note (utiliser une boucle while).
      • Indice : Utiliser Console.WriteLine("Voulez-vous saisir une autre note ? (o/n)");.

    📌 TP 3-2 : Calculatrice avec validation (Niveau : Intermédiaire)

    Compétences visées : - Combiner if/else avec des opérateurs booléens. - Gérer des entrées utilisateur et des erreur. - Utiliser des conditions complexes.

    🔹 Énoncé

    Écrire un programme qui : 1. Demande à l’utilisateur de saisir deux nombres (double). 2. Demande de saisir un opérateur (+, -, *, /). 3. Affiche le résultat de l’opération si elle est valide. 4. Gère les erreurs : - Si l’opérateur est invalide, afficher : "Opérateur non reconnu.". - Si une division par zéro est tentée, afficher : "Erreur : division par zéro.".

    Exemple d’exécution : 

    Saisissez le premier nombre : 10
Saisissez le deuxième nombre : 5
Saisissez l'opérateur (+, -, *, /) : /
10 / 5 = 2

    🔹 Consignes détaillées

    1. Créer un projet : 

      dotnet new console -n TP3-2_Calculatrice
cd TP3-2_Calculatrice
code .

    2. Écrire le code :

      • Utiliser double.TryParse pour lire les nombres.
      • Utiliser une structure if/else if pour gérer les 4 opérateurs.
      • Vérifier la division par zéro avec if (denominateur == 0).

    3. Tester :

      • Tester avec des opérations valides (10 + 5, 20 / 4).
      • Tester avec une division par zéro (10 / 0).
      • Tester avec un opérateur invalide (10 % 5).

    🔹 Extensions pour les rapides

    1. Gestion robuste des entrées :

      • Utiliser double.TryParse et char.TryParse pour éviter les plantages.
      • Afficher un message d’erreur si la saisie n’est pas un nombre ou un opérateur valide.

    2. Ajouter des opérateurs :

      • Ajouter le modulo (%).
      • Ajouter la puissance (Math.Pow(nombre1, nombre2)).

    3. Boucle pour plusieurs calculs :

      • Demander à l’utilisateur s’il veut faire un autre calcul (utiliser while).

    4. Historique des calculs :

      • Stocker chaque calcul dans une liste (List<string>) et afficher l’historique à la fin.

    📌 TP 3-3 : Menu interactif avec switch (Niveau : Avancé)

    Compétences visées : - Utiliser switch pour gérer un menu interactif. - Combiner switch avec des boucles (while). - Gérer des sous-menus et des actions complexes.

    🔹 Énoncé

    Écrire un programme qui simule un menu interactif pour un système de gestion de notes avec les options suivantes :

    ===== Menu Principal =====
1. Ajouter une note
2. Afficher la moyenne des notes
3. Afficher la note maximale
4. Afficher la note minimale
5. Quitter
Choisissez une option :
    • Option 1 : Demander à l’utilisateur de saisir une note et l’ajouter à une liste (List<double>).
    • Option 2 : Calculer et afficher la moyenne des notes (arrondie à 2 décimales).
    • Option 3 : Afficher la note maximale.
    • Option 4 : Afficher la note minimale.
    • Option 5 : Quitter le programme.
    • Gestion des erreurs : Si l’utilisateur saisit une option invalide, afficher "Option invalide. Réessayez." et reafficher le menu.

    Exemple d’exécution : 

    ===== Menu Principal =====
1. Ajouter une note
2. Afficher la moyenne des notes
3. Afficher la note maximale
4. Afficher la note minimale
5. Quitter
Choisissez une option : 1
Saisissez une note : 15
Note ajoutée : 15

===== Menu Principal =====
1. Ajouter une note
2. Afficher la moyenne des notes
3. Afficher la note maximale
4. Afficher la note minimale
5. Quitter
Choisissez une option : 2
Moyenne : 15.00

    🔹 Consignes détaillées

    1. Créer un projet : 

      dotnet new console -n TP3-3_MenuNotes
cd TP3-3_MenuNotes
code .

    2. Écrire le code :

      • Utiliser une boucle while pour afficher le menu en continu.
      • Utiliser un switch pour gérer les options.
      • Stocker les notes dans une List<double>.

    3. Tester :

      • Ajouter plusieurs notes, puis afficher la moyenne, le max et le min.
      • Tester les options invalides (ex : 6, abc).

    🔹 Extensions pour les rapides

    1. Tri des notes :

      • Ajouter une option "6. Trier les notes" qui affiche les notes par ordre croissant.
      • Indice : Utiliser notes.Sort().

    2. Suppression de notes :

      • Ajouter une option "7. Supprimer une note" qui demande l’index de la note à supprimer.
      • Indice : Utiliser notes.RemoveAt(index).

    3. Recherche de notes :

      • Ajouter une option "8. Rechercher une note" qui demande une valeur et affiche si elle existe dans la liste.
      • Indice : Utiliser notes.Contains(noteRecherchee).

    4. Menu contextuel :

      • Après avoir affiché la moyenne/max/min, demander si l’utilisateur veut retourner au menu principal ou quitter.

    5. Sauvegarde des notes :

      • Ajouter une option "9. Sauvegarder les notes" qui écrit les notes dans un fichier texte.
      • Indice : Utiliser File.WriteAllLines("notes.txt", notes.ConvertAll(n => n.ToString())).

    À la fin de cette séance, vous devez être capables de : 1. Écrire des conditions simples avec if/else. 2. Gérer des choix multiples avec else if ou switch. 3. Combiner les conditions avec les opérateurs booléens (&&, ||, !). 4. Utiliser l’opérateur ternaire pour des affectations conditionnelles simples. 5. Éviter les pièges courants (ex : = vs ==, break dans switch). 6. Appliquer les structures conditionnelles à des problèmes concrets (menus, calculs, validations).
